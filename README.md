## Project Overview
Student Task Manager is a lightweight console-based tool designed to help students track and manage daily academic tasks, assignments, and milestones.

### Planned Features
1. Add tasks with title validation (preventing empty titles).
2. Display all tasks with clear ID, title, and completion status.
3. Mark specific tasks as completed by ID.
4. Delete tasks safely by identifier.
5. Automated test suite and CI workflow.
